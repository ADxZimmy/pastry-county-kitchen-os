# Pastry County Kitchen OS

Mobile-first bakery operations dashboard for inventory, recipes, production, costing, orders, and Neon-backed ingredient conversion workflows.

## Development

```bash
npm install
npm run dev
```

## Database

Provision Neon through Vercel or set `DATABASE_URL`, then run:

```bash
npm run db:setup
```

## Checks

```bash
npm test
npm run build
```
